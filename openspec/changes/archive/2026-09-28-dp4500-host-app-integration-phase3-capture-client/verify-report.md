### Issues Found

**CRITICAL**: None.

**WARNING**:

1. **Pattern A implementation drift — UMD script-tag instead of `await import('@digitalpersona/fingerprint')`** — `design.md §4 Pattern A` specifies dynamic ESM import as the R2 mitigation. Phase 3 implements **script-tag injection** (`dp4500-capture-client.ts:512-523`) because the SDK ships as a UMD IIFE with `exports: { ".": { "types": "./dist/fingerprint.sdk.d.ts", "unpkg": "./dist/fingerprint.sdk.min.js" } }` and ambient-only `.d.ts` declarations. Per `apply-progress.md §Deviation 1`, Vite's strict export resolution rejects both `await import('@digitalpersona/fingerprint')` (returns `{}` because the package has no ESM exports) and `import('.../dist/fingerprint.sdk.min.js?url')` (no such export). The script-tag approach **preserves the R2 mitigation** (SDK loads only when the operator opens the capture modal — see Correctness row 5 above) but the implementation mechanism differs from the design template. **Resolution**: update `design.md §4 Pattern A` to document the UMD script-tag fallback for UMD-only packages. **Non-blocker** — the bundling behavior is functionally equivalent; the deviation is documented in `apply-progress.md` and was applied under the apply agent's "ask-on-risk" delivery strategy.

2. **Quality threshold runtime gate deferred (Deviation 3)** — `design.md §4 Pattern C` + spec §"Real capture quality below threshold" specify `qualityScore < 60` → throw `BiometricQualityTooLow`. Phase 3 implements the check at `dp4500-capture-client.ts:387-410` but hard-codes `qualityScore = 100` (line 409) because the SDK's PngImage `SamplesAcquired` event does not carry a numeric score in the payload — quality is reported separately via `onQualityReported`. The **runtime gate** that actually emits `BiometricQualityTooLow` is deferred to a Phase 3.1 follow-up. **Resolution**: wire `onQualityReported` in `captureFingerprint()` to reject the promise with `BiometricQualityTooLow` when score < 60; add a regression test that exercises the wire-up with a stubbed `onQualityReported` event. **Non-blocker** — the type contract is verified; the runtime contract awaits Phase 3.1.

3. **`CaptureFingerprintResult.width` / `.height` always 0 (Deviation 2)** — `design.md §3` specifies `width` + `height` fields in `CaptureFingerprintResult`.
