DP4500 Fingerprint SDK — Phase 1 Probe

Esta página valida que el SDK HID DigitalPersona pueda enumerar y capturar muestras desde el lector DP4500 en este browser. Si los 3 pasos pasan, la Opción A (Browser Web SDK) es viable; si fallan, pivoteamos a Opción B.

SDK: @digitalpersona/fingerprint 1.0.0 (vendored from DP4500 estandar's node_modules). Global: Fingerprint.WebApi.

Setup

  1. Conectá el lector DP4500 al USB.
  2. Abrí esta página en Chrome o Edge (no Firefox, no Safari).
  3. Si el browser pide permiso USB para el lector, aceptalo.
  4. Los pasos deben completarse en orden.
