1. **WSL-only backend invocation.** `backend/backups/services.py:10` imports POSIX-only
   `fcntl`. Native PowerShell `python -m pytest` fails with
   `ModuleNotFoundError: No module named 'fcntl'`. Run backend tests via:
   ```bash
   wsl bash -c "cd /mnt/c/proyectos/proyecto\ C/backend && /mnt/c/Python314/python.exe -m pytest"
   ```
2. **`backend/env/` venv is broken on Windows** (WSL shebangs in `pyvenv.cfg`).
   Always use system Python at `C:\Python314\python.exe`.
3. **`openspec/config.yaml` is partially stale.** `apply.tdd: true` and
   `apply.test_command: "python -m pytest"` are correct NOW; the chained
   `verify.test_command: "python -m pytest && cd ../frontend/aesthetic-clinic && npm run build"`
   needs `VITE_BIOMETRIC_SUSPENDED` env consideration (defaults to `true` in
   `backend/build.sh`). Init does not overwrite (hard rule).
4. **Frontend `npm test` is not wired.** Vitest 3.2.7 IS installed (correcting prior
   cache #57), `vitest.config.ts` is present, and one test file exists
   (`src/services/biometric/__tests__/dp4500-capture-client.test.ts`).
   To enable frontend unit-level TDD add `"test": "vitest run"` to
   `frontend/aesthetic-clinic/package.json`.
5. **No Python linter or formatter configured** on `backend/`. Backend code style
   is conventional; enforce via PR review or add `ruff` as follow-up.
6. **Frontend Playwright e2e** suites exist for biometric suspension
   (`test:e2e:suspension` uses `playwright.suspension.config.ts`). Both
   Playwright scripts share `global-setup.ts` that resets the backend DB.
7. **`feature/cloud-storage-migration` implications**: backend changes that
   touch `backups/` MUST keep `fcntl` behind an OS guard or replace it.
   Any new test in `backend/backups/tests/` runs on Windows hosts only via WSL.
